# THE Z CORPS — RUNNING GAGS
_Living document. A gag is never repeated flat: it either escalates or it retires. Every gag traces to a measured figure in the chronicle._

**Rule of the series:** if it cannot be measured, it is described as unknown. If it can be measured, the number is the number that was measured.

---

## 1. THE COUNTER
- **Visual:** wall-mounted TOOLS / DOMAINS counter. Reads **TOOLS 412 / DOMAINS 97**. Always wrong. Somebody scratched **IT IS NOT 412** into the housing with a screwdriver.
- **Origin:** #2 p.15–16 — wired to a hand sum, wrong on the day it was installed (5 Oct 2026).
- **Escalation ladder:**
  1. #2 — installed, already wrong, nobody looks.
  2. #1 — still 412, still wrong, Scribe will not let it go.
  3. #13 — **a second counter appears** reading TOOLS 300 / DOMAINS 22. Two counters, two numbers, neither right. (Escalated: the lie has been duplicated.)
  4. Next: the counter is *correct for eleven minutes* and everyone finds that more frightening than the lie.
- **Payoff rule:** may only be paid off in the issue where the count is finally *measured* — and the measured number must be lower than 412.

## 2. THE NUMBER THAT WENT DOWN
- **Visual:** six pins in five minutes thirty-five seconds: 272, 290, **281**, 294, 298, 302, 306.
- **Origin:** #2 p.15 — "I added them" / "a total is a claim, a count is a measurement."
- **Escalation:** #1 p.12 (Kimi: "That last one is lower than the one before it.") → #13 (the 281 is found *circled in Jayson's own handwriting* on a printout he does not remember printing).
- **Payoff rule:** pays off when someone proves 281 was the only *measured* number in the list.

## 3. EIGHTY-FOUR IDENTICAL PROGRAMS
- **Visual:** 145 files named `runtime.py`. Fifteen distinct. Eighty-four are the same file.
- **Origin:** #2 p.18 — the first Ctrl-C / Ctrl-V. "That is not a subsystem. That is a nickname."
- **Escalation:** #13 — the eighty-four have started *voting*. They all agree, which is the problem.
- **Payoff rule:** pays off when the eighty-four are merged and the merge is recorded.

## 4. THE GREEN THAT MEANS RED
- **Visual:** a test step that collects 0 items, exits 5, and shows a green check.
- **Origin:** #2 p.19–20. "The check is green because we told it to be green when it fails."
- **Escalation:** #13 — the green check is now *the only thing anyone reads*. A red failure is filed as green within four minutes.
- **Payoff rule:** pays off when a green check is finally, publicly, called a lie — by someone other than Scribe.

## 5. /READY
- **Visual:** a lone endpoint in a dark room. Answers cleanly. Polled by nothing.
- **Origin:** #2 p.21. "It is the only thing in this building that has never lied, and the only thing nobody talks to."
- **Escalation:** #13 — something finally polls it. Once. At 04:12. It answers *too fast*.
- **Payoff rule:** pays off when /ready is the thing that saves someone.

## 6. THE LEDGER THAT WENT QUIET
- **Visual:** the failures ledger. Silent from 29 September. Then eight entries in one day, better written than the chronicle.
- **Origin:** #2 p.22. **Escalation:** #13 — the eight entries are in a hand that is not Scribe's, and one of them is dated tomorrow.
- **Payoff rule:** pays off when Scribe meets the other hand.

## 7. THE DECIMATOR THAT REFUSED
- **Visual:** two decimators. One reports success and does nothing. One refuses to return a broken mesh.
- **Origin:** #2 p.23–24. "This one lies. The other one refuses. I know which one I would keep."
- **Escalation:** #13 — the refusing decimator is the only system that will not accept the new count.
- **Payoff rule:** pays off when the refusing one is asked to destroy something and refuses again.

## 8. HYPERFINE
- **Visual:** an empty space on a shelf where a tool should be. A commission document describing it.
- **Origin:** #2 p.29 — commissioned, searched, absent from every blob, branch and commit message.
- **Escalation:** #13 — a *benchmark result* from hyperfine appears in the ledger. Something ran a tool that does not exist.
- **Payoff rule:** pays off when hyperfine is found — or when it is proven it was never meant to exist.

## 9. THE HOTRAIL BONG (NEW — canon 2026-11-22)
- **Visual:** Gabe's latest invention, on the counter, under the bare bulb. A different absurd build every issue.
- **Origin:** #13 p.6 — the **Copper Coffin** (a length of copper pipe, a jar lid, one hose clamp).
- **Escalation ladder:** each issue Gabe presents a new one with a name and a boast, and it is always *worse engineered* than the last while working *better*.
  1. #13 — Copper Coffin. "It's got a *thermal mass*."
  2. Next — the **Two-Stage Regret**.
  3. Next — the **Bishop** (nobody will explain the name).
- **Payoff rule:** never fully pays off. It is the series' heartbeat. It may only retire if Gabe stops inventing, which would mean Gabe has stopped being Gabe.

## 10. PURPLE SPACE DUST (NEW — canon 2026-11-22)
- **Visual:** a jar of purple dust, glowing violet, on the scratched mirror. **Not green. Not pencil shavings.**
- **Origin:** #13 p.6. **Retcon logged:** #1 p.25 had "glowing green dust"; canon overrides to purple. See `continuity.md`.
- **Escalation:** the dust's glow is the *only* purple in the palette, so it reads as contamination from another reality — which, by #13's twist, it is.
- **Payoff rule:** pays off when someone realises what the dust actually is.

## 11. "IT BUILDS"
- **Visual:** Jayson's entire code review, one line.
- **Origin:** #2 p.2. **Escalation:** #13 — "It builds" is now the *only* approval anyone gives, and it is given to a thing that should not build.

## 12. THE NINTH CRATE
- **Visual:** eight crates in the braid, and a ninth beside them that is not a member.
- **Origin:** #2 p.28. **Escalation:** #13 — the ninth crate has a nameplate now, and the nameplate ends in z.
